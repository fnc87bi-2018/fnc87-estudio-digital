## Arquivos
- `index.html` — estrutura e conteúdo do site.
- `styles.css` — identidade visual e layout responsivo.
- `script.js` — menu mobile e ano automático no rodapé.
- `assets/logo-fnc87-horizontal.png` — logotipo horizontal original aprovado.
- `assets/simbolo-fnc87.png` — símbolo oficial para o destaque e favicon.

## Publicação no GitHub + Cloudflare Pages
1. Baixe e extraia o ZIP.
2. Abra o repositório `fnc87-estudio-digital` no GitHub.
3. Envie os arquivos e pastas mantendo a estrutura acima, na raiz do repositório.
4. Faça o commit na branch `main`.
5. O Cloudflare Pages fará a publicação automática.

Configuração do Cloudflare Pages para este site estático:
- Framework preset: `None`
- Build command: deixar vazio
- Build output directory: `/`
- Root directory: `/`
